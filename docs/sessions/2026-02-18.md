# Session 2026-02-18 — USD Prices in Product Catalog

## Context

Client requested that the `/catalogo` page show prices in both Colombian Pesos (COP) and US Dollars (USD). The USD exchange rate comes from the Banco de la República de Colombia.

---

## Changes Made

### 1. Database: New `exchange_rates` Table [SHARED]

**File modified:** `prisma/schema.prisma` (in both nouvie-sales and nouvie-web)

Added a new `ExchangeRate` model to store currency exchange rates:

```prisma
model ExchangeRate {
  id        String   @id @default(uuid())
  currency  String   @unique
  rate      Decimal  @db.Decimal(10, 2) // COP per 1 unit of currency
  updatedAt DateTime @updatedAt
  @@map("exchange_rates")
}
```

**Initial seed:** 1 USD = 3,660.25 COP (Banco de la República market average rate, 2026-02-18)

**Migration:** Applied via `prisma db push` in nouvie-sales. Schema synced and `prisma generate` run in nouvie-web.

---

### 2. Backend: `getUsdRate()` Function

**File modified:** `lib/products.ts`

Added a new function at the bottom of the file:

- Queries the `exchange_rates` table for the "USD" row
- Returns the rate as a number (e.g., `3660.25`) or `null` if not found
- Error handling returns `null` so the catalog gracefully falls back to COP-only

---

### 3. Frontend: Dual Currency Display in Catalog

**File modified:** `app/[locale]/catalogo/page.tsx`

**Changes:**
- Added `fmtUsd()` formatter — converts COP to USD using the rate and formats with `Intl.NumberFormat("en-US", { currency: "USD" })`
- Changed `getPrice()` to return the raw number instead of a formatted string, so both `fmt()` (COP) and `fmtUsd()` (USD) can use it
- Fetches products and USD rate in parallel with `Promise.all([getProducts(), getUsdRate()])`
- `Card` component now accepts `usdRate` prop

**USD prices shown in 3 locations:**
1. **Card component** (hogar concentrates, hogar kits, individual capilar) — smaller gray text below COP price
2. **Treatment cards** (capilar kits) — below the kit price
3. **Institucional presentation prices** — below each size price

**USD disclaimer banner** added between the cover and hogar sections:
- Shows: "Precios en USD según la tasa del Banco de la República · 1 USD = $3,660"
- English translation below
- Link to Banco de la República source page
- Only renders when exchange rate exists in DB

---

### 4. Translation Messages

**Files modified:** `messages/es.json` and `messages/en.json`

Added two new keys under `catalog.footer`:
- `usdDisclaimer`: "Precios en USD según la tasa del Banco de la República" / "USD prices based on the Banco de la República exchange rate"
- `usdSource`: "Fuente: Banco de la República de Colombia" / "Source: Banco de la República de Colombia"

## Design Decision: Exchange Rate Table vs USD Column

**Decision:** Store a single exchange rate value in `exchange_rates` table instead of adding a `priceUsd` column to each product.

**Rationale:**
- Updating the rate monthly requires changing only ONE row
- All product prices reflect the new rate automatically
- No need for a script to recalculate all product rows
- Simpler data model

**Source:** Banco de la República de Colombia — https://suameca.banrep.gov.co/estadisticas-economicas/informacionSerie/1.1/tasa_cambio_peso_colombiano_dolar_comportamiento_mercado_dolar_dia_tiempo_real

## Updating the Rate

To update the USD exchange rate, run this SQL on the database:

```sql
UPDATE exchange_rates SET rate = 3700.00, "updatedAt" = NOW() WHERE currency = 'USD';
```

Replace `3700.00` with the current Banco de la República rate. All catalog prices will reflect it immediately.
