## Architecture Decisions

1. **Hardcoded product data** — Products live in `lib/promomix-config.ts`, not fetched from the database. This keeps the promo page fast and independent from the general catalog.

2. **No API routes** — Entire experience is client-side. State managed with `useState` hooks. No server actions, no database queries.

3. **WhatsApp as order channel** — Instead of building an order/checkout system, the CTA generates an encoded WhatsApp message with the full order details (products, quantities, subtotals, savings, customer info).

4. **Client component** — The builder uses `"use client"` because it needs interactivity (quantity controls, real-time calculations, form inputs).

5. **Luxury editorial design** — Navy background with turquoise/gold accent glows, rose theme for Hogar products, amber theme for Capilar products. Matches Nouvie brand palette from `globals.css`.

## Key UI Features

- **Sticky budget tracker** — Always visible, shows progress bar toward $300,000 minimum with color coding (turquoise -> green -> amber)
- **Real-time calculations** — Total, savings, and remaining amount update instantly as quantities change
- **Validation** — CTA button is disabled until minimum is met; shows remaining amount needed
- **Overage display** — When over $300,000, shows the excess amount
- **Responsive grids** — 1 column mobile, 2 columns tablet, 3 columns desktop
- **Product cards** — Show discount badge, strikethrough base price, promo price, quantity controls, and subtotal
- **Optional customer info** — Name and phone fields included in WhatsApp message if provided
- **Home page banner** — Full-width clickable banner promoting the PromoMix with "40%" badge and "Armar mi mix" CTA
